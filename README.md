# 📊 Instore Sales & Activation Dashboard

An interactive **Power BI dashboard** built using FMCG activation and sales data to analyze sales performance, conversion efficiency, SKU trends, and store-level insights across multiple zones and cities.

---

# 🚀 Project Objective

The goal of this project is to transform raw FMCG activation data into meaningful business insights through:

✔ Sales Analysis  
✔ Conversion Tracking  
✔ SKU Performance Monitoring  
✔ Store-wise Performance Evaluation  
✔ Interactive Business Reporting  

---

# 🛠 Tools & Technologies Used

| Tool | Purpose |
|---|---|
| Power BI | Dashboard Development |
| Excel | Data Cleaning & Preparation |
| Power Query | Data Transformation |
| DAX | KPI & Measure Calculations |

---

# 📁 Dataset Information

The dataset includes FMCG field activation and sales records containing:

- 📅 Date
- 🌍 Zone / State / City
- 🏪 Outlet Name
- 👨‍💼 Promoter Details
- ⏱ Worked Hours
- 📈 Total Approach
- 🎯 Total Sampled
- 📞 Productive Calls
- 🛒 Units Sold
- 💰 Sales Amount
- 📦 Opening & Closing Stock
- 🧂 SKU-wise Product Sales

---

# 📌 Dashboard Features

✨ KPI Cards  
✨ Sales Trend Analysis  
✨ Funnel Analysis  
✨ Zone-wise Average Sales  
✨ Top Cities by Conversion Rate  
✨ SKU Performance Analysis  
✨ Store-wise Sales Performance  
✨ Interactive Slicers & Filters  

---

# 📊 Key KPIs Tracked

| KPI | Description |
|---|---|
| Total Sales Amount | Overall revenue generated |
| Total Units Sold | Total quantity sold |
| Conversion Rate | Productive calls converted into sales |
| Productive Call Rate | Sampling to productive call ratio |
| Sampling Rate | Approach to sampled conversion |
| SKU Sales | Product-level performance |

---

# 🔍 Key Insights

✅ North Zone recorded the highest average sales performance.  

✅ Howrah achieved the highest conversion rate among all cities.  

✅ Masala SKU emerged as the top-selling product.  

✅ 44.7% productive calls converted into unit sales.

# ⚙ Workflow

```text
1. Data Cleaning in Excel
2. Data Transformation using Power Query
3. KPI Calculation using DAX
4. Dashboard Creation in Power BI
5. Business Insight Generation
```
